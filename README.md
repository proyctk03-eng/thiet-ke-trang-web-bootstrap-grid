# [Bài tập] Thiết kế Trang Web với Bootstrap Grid System

Bài tập luyện tập sử dụng Bootstrap Containers và Grid System để tạo bố cục trang web responsive theo chuẩn CodeGym.

## Cấu trúc trang web
- **Header**: Tiêu đề trang web và giới thiệu mục tiêu.
- **Navbar**: Menu điều hướng responsive với Bootstrap Navbar và menu thả xuống (Dropdown).
- **Main Content & Sidebar (Grid System)**:
  - Trên màn hình Desktop (≥ 992px): Main Content chiếm `col-lg-8` (8/12 cột), Sidebar chiếm `col-lg-4` (4/12 cột).
  - Trên màn hình Mobile (< 992px): Cả Main Content và Sidebar tự động xếp chồng theo chiều dọc với `col-12` (100% chiều rộng).
- **Footer**: Thông tin bản quyền.

## Công nghệ sử dụng
- HTML5
- Bootstrap 5.3.0 CDN (CSS & JS Bundle)
